# Attribution and scope

Public ESPN nativeevent identity/schedule/state and response schema metadata, through existing C permitted nativeevent facts route. Full responses were temporary in memory only. No articles, names, biographies, injury descriptions, media or offer/odds values were retained. Metadata about missing roster/inactive components is a source qualification result, not a player availability conclusion.

Existing nflverse roster and earlier report facts are referenced with their original observation clocks in the report; no current or historical availability is synthesized. C nativeevent source observation is independent of any forecast, line selection or production admission.
