## What the proxy and personalization actually test

C's player context estimates past targeted depth/down mixtures and target volume relative to qualified team attempts. It does not observe starting alignment, untargeted routes, route openness, motion actor, man/zone assignments or true target-per-route rates. The 29-field FTN charting inspected earlier cannot supply those missing denominators. The field is named pass destination, not alignment.

Five deterministic ordinary/winning/losing/verified-zero-target/unknown cases were independently rebuilt from retained PBP and official facts, not just cached vectors. One existing source hold remains: 2025 SEA–PIT/PIT has 34 PBP versus 35 official attempts; its context is withheld. Explicit unknowns are not filled from participation.

For known zero-target histories with positive team attempts, the true target-volume ratio is zero. v1.1 retains zero counts but omits the derived ratios together with undefined target-quality rates. `ctx_missing` therefore means **no positive-target context**, not source absence/DNP. This deliberate coarsening affects 272 query vectors (108 in 2026). No measured accuracy cost is asserted, and old features are not silently rewritten.

Opponent response is genuinely bin-specific in this proxy. For bin j, earlier offense rate is `(completions_j + 20*earlier_league_rate_j)/(targets_j+20)`; game residual is `C_j-N_j*q_j`; opponent-bin effect is `sum(residual_j)/(sum(N_j)+40)`. Interaction is the dot product of the player's earlier target-mixture vector and those distinct effects; down uses the analogous partition. It does not collapse one identical scalar across exhaustive shares.

Worked ATL example: an earlier offense's 0–9-air-yard rate is `(107+20*(5516/7418))/(133+20)=0.79654858`. Ten catches on 15 targets give residual −1.94822874. Across all bins, the main completion-residual feature is −7.86253224/(279+40)=−0.02464744. The distinct 0–9 bin effect is −5.71860336/(136+40)=−0.03249206; weighting the full bin vector by this player’s earlier mix gives −0.02584664. Residual numerators and opportunity denominators are summed deliberately, not averaged as equally weighted game percentages. This is earlier team-quality adjustment, not a fully identified causal defense/QB/receiver talent estimate. See [raw review/equations](C_RAW_REVIEW.json).

P1/P2 share covariates, Poisson objective and regularization; P2 adds jointly fitted penalized player/team/defense intercepts, with unseen effects zero. P3's supported branch uses its own eight known appearances and own tail, but the full system falls back to shared P1. It is not an entirely own-information forecasting system.
