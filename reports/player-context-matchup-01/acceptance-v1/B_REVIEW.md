## Mathematical meaning and scope

B's defense residual is genuinely context-specific: for each down/depth cell j, `(completions_j - earlier-offense-quality expected completions_j)/(attempts_j+100)`. Expectation uses the prior QB's earlier smoothed rate, with the strength-20 pooled context reference calculated before that prior game. Team-game aggregation precedes selecting the last 16 eligible games; multiple QB rows contribute actual throw counts rather than duplicate equal game weights. The E3 vector is `predicted_own_mix_j * defense_residual_j` across 25 distinct cells. The checked residual range is -0.0364746 to +0.0315517, so it is not one identical scalar multiplied by exhaustive shares. This remains a reconstructed QB-completion response, not causal defense talent or receiver alignment.

Full-game P1/P2/P3 conversion uses a predicted down/depth mix and predicted attempt exposure. It does not insert target-game realized attempts. Shared and partial models use the same conditional covariates/family; partial pooling adds player effects. P3 fits its coefficients on sufficient own outcomes but still consumes shared context estimates and falls back to P1. It is not an entirely own-information model. P1 versus direct E2 is a complete-system comparison: representations/covariates differ, despite sharing a source-context group.

The earlier menu chose 8 appearances/strength20 by saved 2024 W1–8 full-game completion NLL (302 QB rows), before the 2025/2026 evaluations.
